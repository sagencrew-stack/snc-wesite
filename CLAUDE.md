# snc-wesite — Sage & Crew marketing site

Marketing website for Sage & Crew (sagencrew.in). Migration project: moving the site **off Wix onto a Next.js site hosted on Vercel**.

## Stack
- **Next.js** + **Tailwind**
- **GitHub:** `sagencrew-stack/snc-wesite`, branch `main` (`gh auth switch --user sagencrew-stack`)
- Deploys via Vercel; dev server runs on port 3002 locally

## Notes
- `.claude/` is gitignored (local config only).
- Run `/init` in Claude Code to generate a fuller map of the codebase.
